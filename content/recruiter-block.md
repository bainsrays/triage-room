# What this demonstrates

Triage Room is 11 realistic fintech support tickets I built to sharpen the fundamentals I already use day to day: payments investigation, merchant API/webhook debugging, KYC judgment calls, chargeback handling, and crypto/fiat remittance edge cases across Nigerian and cross-border rails (NIP transfers, USSD, USD virtual accounts, USDT-to-NGN conversion).

Each ticket is worked the way I'd actually work it — pull the transaction log, check the SQL query that proves the cause, read the webhook error, cross-reference a rate-history snapshot — before diagnosing, escalating, or replying. Every case is scored on five things that matter in this kind of role: whether I found the real root cause, whether I checked evidence before guessing, whether the resolution stays compliant (no over-promising, no leaking sensitive data), how clear the customer reply is, and whether escalation judgment is right.

It's not a game. It's a fixed, reviewable set of cases with a public rubric, built to show how I think through the kind of incidents that show up in fintech and payments support queues every day.
